## What's New in Claude Code This Week

### v2.1.178 — Agent teams simplified; `Tool(param:value)` permissions; nested skills (June 15)

- **Agent teams overhauled** — `TeamCreate` and `TeamDelete` tools removed. Every session now has one implicit team. Spawn teammates directly via `Agent(name: "my-agent")` with no setup step needed. The `team_name` parameter on `Agent` is still accepted but ignored.
- **`Tool(param:value)` permission syntax** — permission rules can now match on a tool's input parameters with `*` wildcard. Examples: `Agent(model:claude-fable-5)` blocks spawning the expensive model in subagents; `Bash(command:pkill*)` blocks specific commands by argument rather than just by prefix. Complements existing `Bash(npm run *)` syntax.
- **Nested `.claude/skills` auto-load** — skills in nested `.claude/skills/` subdirectories now load automatically when working on files there. On a name clash, the nested skill appears as `<dir>:<name>` so both remain available.
- **Auto mode + subagent classifier** — subagent spawns are now evaluated by the auto mode classifier before launch, closing a gap where a subagent could request a blocked action without review.
- `/doctor` redesigned with consistent flat tree layout and clearer section status icons.
- `/bug` now requires a description before submitting.

Source: [CHANGELOG v2.1.178](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.181 — `/config key=value`; ⚠️ 0-byte file fix for cloud-synced folders (June 17)

- **`/config key=value` in-session** — set any settings key from the prompt without editing JSON: `/config thinking=false`, `/config model=claude-fable-5`. `/config --help` (added v2.1.183) lists all shorthand keys.
- **`sandbox.allowAppleEvents` opt-in** — sandboxed commands can now send Apple Events on macOS (`osascript` etc.). Opt-in only; no default change.
- **`CLAUDE_CLIENT_PRESENCE_FILE` env var** — point at a marker file to suppress mobile push notifications while you're at the machine. Useful for focus sessions.
- **⚠️ CRITICAL BUG FIX — 0-byte/truncated files on cloud-synced folders** — `Write` and `Edit` could produce 0-byte or truncated files on Dropbox, iCloud Drive, and other network-backed folders. **ChefAcademy lives at `~/Dropbox/Mac/Desktop/ChefAcademy/`** — Marina should update Claude Code to v2.1.181+ immediately if not already on this version.
- **Prompt caching fix on custom `ANTHROPIC_BASE_URL`** — caching was silently not reading on custom base URLs due to a per-request attestation token changing every turn. Both projects proxy through the Cloudflare Worker (custom `ANTHROPIC_BASE_URL`). After updating to v2.1.181+, cache reads should resume, reducing repeat-turn API costs.
- Fixed `open`, `osascript`, and browser-based auth flows failing with macOS error -600.
- Fixed startup crash when `.claude.json` has corrupted null project entries.

Source: [CHANGELOG v2.1.181](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.183 — Auto mode blocks destructive git; `attribution.sessionUrl` (June 19)

- **Auto mode now blocks destructive git commands** — when running in auto mode, `git reset --hard`, `git checkout -- .`, `git clean -fd`, `git stash drop` are blocked unless you explicitly asked to discard local work. `git commit --amend` is blocked when the current agent session didn't make that commit. `terraform destroy` / `pulumi destroy` / `cdk destroy` also blocked unless explicitly requested. Free safety improvement for both projects; no config change needed.
- **`attribution.sessionUrl` setting** — `"attribution": {"sessionUrl": false}` in settings.json omits the claude.ai session link from commit messages and PRs in web/Remote Control sessions. Relevant to this maintenance routine.
- **`/config --help`** — lists all `/config` shorthand keys with descriptions.
- **Fixed WebSearch returning empty results in subagents** — ChefAcademy's `code-reviewer` and `adaptive-layout-engineer` agents can now reliably use web search within their tasks.
- Fixed scheduled task/webhook trigger deliveries being treated as keyboard input (they can no longer approve a pending action or set the session title in auto mode).

Source: [CHANGELOG v2.1.183](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.185 — Stream-stall hint timing adjusted (June 20)

- Stream-stall hint now reads "Waiting for API response · will retry in …" and triggers after **20 seconds** of silence (was "No response from API · Retrying in …" at 10s). Less alarming for slow proxy responses like those from the Cloudflare Worker under load.

Source: [CHANGELOG v2.1.185](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
