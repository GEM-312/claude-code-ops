## What's New in Claude Code This Week

### v2.1.186 — MCP auth CLI; `!`-bash auto-responds; skill frontmatter keys; Stop hooks get `additionalContext` (June 22)

- **`claude mcp login/logout <name>`** — authenticate MCP servers directly from the CLI without re-running full MCP setup flows.
- **`!` bash mode auto-responds** — commands run via the `!` prefix now trigger Claude to respond automatically. Disable with `"respondToBashCommands": false` in settings if you want silent execution.
- **Skill frontmatter: new keys** — `display-name`, `default-enabled`, `fallback`, and `metadata.*` now accepted in SKILL.md YAML (all three casings: kebab-case/snake_case/camelCase). `default-enabled: false` lets you ship dev-only skills disabled until explicitly turned on.
- **Stop / SubagentStop hooks get `additionalContext`** — hooks can now return `hookSpecificOutput.additionalContext` to give Claude structured feedback and keep the turn going without being labeled a hook error.
- **Skills section in `/plugin`** — installed skills now listed under a dedicated section.
- **`/review <pr>` uses code-review engine** — `/review <pr#>` now runs the same engine as `/code-review medium`.
- **Fixed: `Agent(type)` deny rules not enforced for named subagent spawns** — the `Tool(param:value)` permission syntax added in v2.1.178 now correctly enforces deny rules for named subagents.
- **Fixed: Workflow `agent({schema})` looping on schema validation failures** — subagents no longer retry indefinitely on repeated schema mismatches.
- **Fixed: hooks with comma-separated matchers silently never firing** — any hook that used `"matcher": "Bash,Edit"` style was silently broken; now fires correctly.
- Fixed background session recaps being duplicated.
- Fixed `Agent(type)` deny rules and `Agent(x,y)` allowed-types restrictions not enforced for named subagent spawns.

Source: [CHANGELOG v2.1.186](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.187 — `sandbox.credentials`; org model restrictions; fixed MCP hangs + CJK paste (June 23)

- **`sandbox.credentials` setting** — `"sandbox": {"credentials": true}` blocks sandboxed Bash commands from reading credential files and secret environment variables. Belt-and-suspenders for projects with `APIKeys.swift` deny rules (only effective when running in sandbox mode).
- **Org-configured model restrictions** — org admins can restrict which models appear in the model picker and `--model` flag.
- **Fixed: remote MCP tool calls hanging for 5 minutes** — they now abort with an error instead of blocking the session indefinitely.
- **Fixed: Claude Code Remote sessions ~2.7s slower to start** — regression introduced earlier, now resolved.
- **Fixed: Korean/CJK text pasted as mojibake** — in terminals that deliver paste as per-byte extended-key events, CJK text now pastes correctly.
- **Fixed: `--json-schema` and Workflow `agent({schema})` structured output** — reliable structured output for both CLI and workflow scripts.

Source: [CHANGELOG v2.1.187](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.191 — `/rewind`; 37% CPU reduction during streaming; hook comma-matcher fix (June 24)

- **`/rewind`** — resume a conversation from before the last `/clear` was run. Useful for recovering lost context after an accidental clear.
- **37% CPU reduction during streaming** — text updates now coalesced to 100ms intervals instead of per-token. Noticeable for long streaming responses, especially over the Cloudflare Worker proxy.
- **Fixed: `/permissions` Recently-denied tab not persisting approvals on close** — denials now persist correctly across closes.
- **Reduced long-session memory growth** from terminal output cache.
- Fixed background agents resurrecting after being stopped.
- Fixed scroll position jumping to bottom while reading earlier output during streaming.
- Improved MCP server reliability: capability discovery retries transient network errors.

Source: [CHANGELOG v2.1.191](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.193 — `autoMode.classifyAllShell`; live file autocomplete; memory-pressure reaping (June 25)

- **`autoMode.classifyAllShell`** — routes all Bash/PowerShell commands through the auto-mode classifier (not just those matching existing auto-mode patterns). Stricter safety for fully automated sessions.
- **Auto-mode denial reasons** — now surfaced in transcript, denial toast, and `/permissions` recent denials. Easier to diagnose why an auto-mode run blocked a command.
- **Live file path autocomplete in `!` bash mode** — Tab-completes file paths when running inline bash commands.
- **Automatic memory-pressure reaping** — idle background shell commands are automatically reaped when memory pressure is detected. Disable with `CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP=1`.
- **Plugin auto-rename follows marketplace renames** — when a plugin is renamed in the marketplace, `settings.json` automatically updates to the new name on next load.
- Fixed pinned background agents being re-prompted after every auto-update.
- Fixed backgrounding spuriously cancelling with "N background tasks would be abandoned."

Source: [CHANGELOG v2.1.193](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.195 — Hook hyphenated matcher exact-match fix; `CLAUDE_CODE_DISABLE_MOUSE_CLICKS` (June 26)

- **Fixed: hook matchers with hyphenated identifiers now exact-match** — matchers like `"code-reviewer"` or `"mcp__brave-search"` were accidentally substring-matching other identifiers; now exact-match only. Affects any project with hook `matcher` values containing hyphens or double-underscores.
- **`CLAUDE_CODE_DISABLE_MOUSE_CLICKS` env var** — disables mouse click/drag/hover in fullscreen mode while preserving wheel scroll. Useful for terminal setups where accidental clicks interrupt input.
- Fixed external plugins enabled only by project `.claude/settings.json` not requiring explicit install consent on every loader path.
- Fixed background agent daemons running unreachable when control socket fails to start.
- Fixed voice dictation on macOS after default input device changes.
- Fixed voice dictation auto-submit for CJK languages (Japanese, Chinese, Thai).

Source: [CHANGELOG v2.1.195](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
