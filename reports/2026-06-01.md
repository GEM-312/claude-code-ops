## What’s New in Claude Code This Week

### v2.1.152 (May 27) — Hooks + Skills overhaul

- **New `MessageDisplay` hook event** — fires when assistant text is about to render; hooks can transform or suppress the displayed text. Useful for stripping boilerplate, injecting banners, or redacting sensitive output. Source: [changelog v2.1.152](https://code.claude.com/docs/en/changelog)
- **`SessionStart` hooks: `reloadSkills: true`** — returning this from a SessionStart hook re-scans all skill directories in the same session; skills installed by the hook are immediately available without a restart. Source: changelog v2.1.152
- **`SessionStart` hooks: `hookSpecificOutput.sessionTitle`** — returning this sets the session’s display title on startup and resume. Source: changelog v2.1.152
- **`disallowed-tools` frontmatter for skills/commands** — add `disallowed-tools: [Tool1, Tool2]` in a skill’s frontmatter to strip those tools from the model while the skill is active. Useful for locking a skill to read-only or preventing web fetches. Source: changelog v2.1.152
- **`/reload-skills` command** — re-scan skill directories without restarting the session. Previously required a quit-and-reopen. Source: changelog v2.1.152
- **`pluginSuggestionMarketplaces` managed setting** — admins can allowlist org plugin marketplaces for context-aware suggestions. Enterprise only. Source: changelog v2.1.152
- **Auto mode no longer requires opt-in consent.** Source: changelog v2.1.152
- **Bug fix: hooks writing to terminal corrupted interactive prompts.** Affected any project with PreToolUse hooks. Source: changelog v2.1.152
- **Bug fix: `Skill(name *)` permission rules now work as prefix match.** Wildcard skill rules were silently ignored before this. Source: changelog v2.1.152

### v2.1.153 (May 28) — Subagent + MCP fixes

- **Status line commands receive `COLUMNS` and `LINES`** env vars — useful for terminal-width-aware status scripts. Source: changelog v2.1.153
- **Bug fix: subagent MCP servers now respect `--strict-mcp-config`** (previously ignored). Source: changelog v2.1.153
- **Bug fix: `Agent(subagent_type: \'claude\')` no longer runs in undocumented temporary worktree.** Source: changelog v2.1.153

### v2.1.154 (May 28) — Opus 4.8 + Dynamic Workflows

- **Opus 4.8 released.** Default effort level is `xhigh` (`/effort xhigh`). Source: changelog v2.1.154
- **Dynamic Workflows** — ask Claude to orchestrate work across tens to hundreds of agents; view runs with `/workflows`. Source: changelog v2.1.154
- **Fast mode on Opus 4.8: 2.5× speed at 2× standard rate** — 3× cheaper than Fast mode on Opus 4.6. Source: changelog v2.1.154
- **Lean system prompt is now default** for Opus 4.8 and all newer models; Haiku, Sonnet, and Opus ≤4.7 keep the full system prompt. Source: changelog v2.1.154
- **`CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE` deprecated and removed 2026-06-01.** Replacement: `/model claude-opus-4-6` then `/fast on`. Source: changelog v2.1.154
- **Stdio MCP servers now receive `CLAUDE_CODE_SESSION_ID` and `CLAUDECODE=1`** env vars. Source: changelog v2.1.154
- **Plugins can declare `defaultEnabled: false`** in `plugin.json`; enable per-project with `/plugin`. Source: changelog v2.1.154
- **`/simplify` is now a cleanup-only review** (reuse, simplification, efficiency, altitude) that auto-applies fixes via `/code-review --fix`. Source: changelog v2.1.154

### v2.1.156 (May 29)

- **Bug fix: Opus 4.8 thinking blocks being modified** causing API errors. Source: changelog v2.1.156

### v2.1.157 (May 29) — Plugin + worktree polish

- **Skills in `.claude/skills/` now auto-load without marketplace requirement.** Any `.md` file in `.claude/skills/` is immediately available — no marketplace publishing needed. Both projects already benefit from this. Source: changelog v2.1.157
- **`claude plugin init <name>`** — scaffolds new plugin/skill in `.claude/skills/<name>/`. Source: changelog v2.1.157
- **“Workflow keyword trigger” can be disabled** in `/config` — prevents the word “workflow” from triggering the workflow system (relevant if Marina’s sessions are triggering this inadvertently). Source: changelog v2.1.157
- **`EnterWorktree` can now switch between Claude-managed worktrees mid-session.** Source: changelog v2.1.157
- **Startup banners removed:** “bash commands will be sandboxed” and “/ide for …” toasts are gone. Source: changelog v2.1.157

### v2.1.158 (May 30)

- **Auto mode on Bedrock, Vertex, and Foundry** for Opus 4.7 and Opus 4.8 (opt in: `CLAUDE_CODE_ENABLE_AUTO_MODE=1`). Source: changelog v2.1.158

### v2.1.159 (May 31)
