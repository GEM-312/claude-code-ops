## What's New in Claude Code This Week

### v2.1.169 — `--safe-mode`, `/cd` command, `post-session` hook (June 8)

- **`--safe-mode` flag** — disables all customizations (hooks, skills, MCP, slash commands) in one flag. Useful for troubleshooting when hooks or skills are misbehaving. No config change needed; it's a launch-time override.
- **`/cd` command** — moves the session to a new working directory without restarting. Useful when switching between RAA and ChefAcademy in the same terminal.
- **`disableBundledSkills` setting** — new `settings.json` key; hides all bundled default skills/workflows when `true`. Both projects rely on custom project skills; this setting lets you suppress any conflicts with Claude Code's own built-in skill set.
- **`post-session` lifecycle hook** — fires after a session ends on self-hosted / remote runners. Not a project-level `settings.json` hook; it's runner infrastructure. Relevant to this maintenance routine (fires when the weekly agent session ends), but not something to add to RAA or ChefAcademy's config.

Source: [CHANGELOG v2.1.169](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.170 — **Claude Fable 5** (June 9)

- **Introducing Claude Fable 5** — a new "Mythos-class" model described as exceeding all previously available models for general use. Model ID: `claude-fable-5`. Available in `/model` picker immediately.
- Fixed sessions not saving transcripts when launched from VS Code integrated terminal.

Source: [CHANGELOG v2.1.170](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.172 — Sub-agents spawn sub-agents (June 10)

- **Sub-agents can now spawn sub-agents** up to 5 levels deep. Previously agents were single-level. ChefAcademy's `code-reviewer` and `adaptive-layout-engineer` agents can now themselves invoke further agents if their task warrants it.
- Plugin marketplace search bar added.
- AWS region auto-detection from config files (not relevant to these projects).

Source: [CHANGELOG v2.1.172](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.173 — Fable 5 name normalization fix (June 11)

- Fixed Fable 5 model name normalization; resolved sandbox warning edge cases.

Source: [CHANGELOG v2.1.173](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.174 — `wheelScrollAccelerationEnabled` (June 12)

- **`wheelScrollAccelerationEnabled` setting** — `false` disables mouse-wheel scroll acceleration in fullscreen mode. UI preference; not relevant to project config.
- `/model` picker now shows the model family that "Default" resolves to.

Source: [CHANGELOG v2.1.174](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.175 — `enforceAvailableModels` managed setting (June 12)

- **`enforceAvailableModels` managed setting** — when enabled in an org/managed context, prevents the Default model from falling back to a disallowed model. Managed-only (enterprise/admin); not applicable to project `settings.json`.

Source: [CHANGELOG v2.1.175](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### v2.1.176 — `footerLinksRegexes`, session language titles (June 12)

- **`footerLinksRegexes` setting** — array of regexes; matching URLs get badge links in the Claude Code footer row. Could be used to surface the ops repo or project docs in the footer, but this is cosmetic.
- Session titles now generated in the conversation language.
- Bedrock credential caching extended to use API `Expiration` field instead of fixed 1-hour window (not relevant — these projects use Cloudflare Worker, not Bedrock).
- **Hook `if` conditions fixed** — `if` field patterns like `Edit(src/**)` and `Read(~/.ssh/**)` now match correctly. ChefAcademy's bash-guard uses `"matcher": "Bash"` (not an `if` field), so no impact. RAA still has no hooks.
- `/copy` and mouse-selection copy now reach system clipboard inside tmux over SSH.

Source: [CHANGELOG v2.1.176](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
