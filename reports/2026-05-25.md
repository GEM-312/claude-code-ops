## What's New in Claude Code This Week (v2.1.146 – v2.1.150)

Versions released approximately May 20–23, 2026. Previous report (2026-05-20) covered v2.1.139–v2.1.145.

### v2.1.146 (~May 21)
- **`settings.autoMode.hard_deny`** — new nested field under `autoMode` in settings.json; rules here block unconditionally in auto mode regardless of user intent or allow-exceptions (stricter than `autoMode.deny` which can be overridden). Source: web search / [releasebot.io](https://releasebot.io/updates/anthropic/claude-code)
- **`CLAUDE_CODE_PLUGIN_PREFER_HTTPS`** env var — set truthy to clone GitHub plugin sources over HTTPS instead of SSH (useful in corp environments where SSH outbound is blocked)
- **Security fix: `permissions.deny` now reliably overrides PreToolUse hook `permissionDecision`** — prior to this, a hook voting `allow` could silently bypass a deny rule; both projects' deny rules are now fully enforced on ≥2.1.146. Source: [web search summary](https://www.claudeupdates.dev)
- Fixed: MCP paginated `tools/list` only returning first page — tools on page 2+ were silently unavailable
- Fixed: MCP images with unsupported MIME types (e.g., SVG) crashing conversations
- Fixed: Remote-session login failing with "Can't access this organization"
- Improved: `/feedback` now includes pre-compaction conversation context

### v2.1.147 (May 22)
- **Pinned background sessions** (`Ctrl+T` in `claude agents`) — pinned sessions survive idle timeouts and Claude Code auto-updates; evicted last under memory pressure. Source: [claudeupdates.dev v2.1.149](https://www.claudeupdates.dev/version/2.1.149) / [DevelopersIO](https://dev.classmethod.jp/en/articles/20260524-claude-code-updates-v2-1-150/)
- **`/code-review --comment`** — posts `/code-review` findings as inline GitHub PR comments directly from the CLI. Source: same
- Auto-updater hardened: retries transient network failures, reports specific error category + OS error codes, shows current version on failure

### v2.1.148 (May 22)
- **Hotfix: Bash tool returning exit code 127 on all commands** — regression introduced in v2.1.147; if you hit unexplained Bash failures, `claude update` to ≥2.1.148 immediately

### v2.1.149 (May 23)
- **`/usage` per-category breakdown** — cost now itemized by skills, subagents, plugins, and per-MCP-server; replaces single aggregate number. Source: [claudeupdates.dev v2.1.149](https://www.claudeupdates.dev/version/2.1.149)
- **GFM task list checkboxes** (`- [ ]` / `- [x]`) render natively in TUI
- Security: PowerShell `cd` permission bypass patched
- Security: sandbox worktree write allowlist corrected
- 20+ bug fixes: `/diff` keyboard scrolling, transcript view freeze, slash-command arg hints, remote session rename sync

### v2.1.150 (May 23)
- Internal infrastructure only; no user-facing changes
